🔬 Methodology

Data Sources

  • Satellite: Landsat 8 and Landsat 9
  • Product: Collection 2 Level-2 Surface Reflectance
  • Resolution: 30 meters
  • Bands Used: B1-B7 (Coastal, Blue, Green, Red, NIR, SWIR1, SWIR2)

Indices Calculated

  • NDVI: (NIR - Red) / (NIR + Red) - Vegetation health indicator
  • NBR: (NIR - SWIR2) / (NIR + SWIR2) - Forest disturbance indicator
  • dNBR: NBR_initial - NBR_final - Change detection metric

Classification Thresholds

Deforestation severity classification based on dNBR values:

  • Reforestation: dNBR < -0.1
  • No Change: -0.1 ≤ dNBR < 0.1
  • Low Deforestation: 0.1 ≤ dNBR < 0.27
  • Moderate Deforestation: 0.27 ≤ dNBR < 0.44
  • High Deforestation: 0.44 ≤ dNBR < 0.66
  • Severe Deforestation: dNBR ≥ 0.66
